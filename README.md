# Shiba System 🍛 - Restaurant Management

Complete restaurant management system built from notebook.

## Modules (8)
1. Purchase - Store Supplies
2. Kitchen
3. Sales & Collection / Shortage
4. Inventory
5. Expenses
6. Staff Meal
7. Kitchen Production
8. Summary Dashboard

## Tech Stack
- Frontend: HTML + TailwindCSS + Vanilla JS (Colourful Bright UI)
- Backend: Python Flask + SQLite
- Storage: localStorage (offline) + API sync
